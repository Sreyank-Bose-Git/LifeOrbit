## 🌟 Overview

**LifeOrbit OS** is a high-performance, local-first life planner and universal activity tracker inspired by modern dashboard ergonomics and streaming platform architectures. Built with React, TypeScript, and Tailwind CSS, it combines zero-friction habit logging, quantifiable goal meters, project milestones, AI coaching feedback, ambient soundscapes, and multi-account space management into a single cohesive interface.

---

## ✨ Key Features

- **🎬 Netflix-Style Multi-Account Spaces**: Switch seamlessly between different life profiles, workspaces, or roles with custom avatars and isolated state storage.
- **🎧 Procedural Web Audio Engine**: 100% offline ambient soundscapes (**Cyber Synth**, **Deep Space**, **Rain & Thunder**, **Zen Bowls**, **Lo-Fi Vinyl**, and **Binaural Alpha/Gamma Waves**) plus tactile UI sound effects.
- **🪐 Cinematic Entry & Emoji Reactor**: Epic orbital opening logo animation with floating ambient celebration emojis and customizable GPU-accelerated background atmospheres (Aurora, Starfield, Cyber Matrix, Quantum Mesh).
- **⏱️ Persistent Mini Focus Player**: Pomodoro & deep work timer with auto-docking and smart minimize controls.
- **📊 YouTube-Style Orbit Shelf & Navigation**: Pinned left sidebar with confined internal scrolling (`h-screen overflow-hidden` with isolated main content scroll), command palette (`Cmd+K`), and quick-check momentum drawers.
- **📈 Advanced Analytics & Trophies**: Gamified XP leveling system, streak trackers, milestone roadmaps, and D3/Recharts data visualizations.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Motion (Framer Motion), Lucide Icons, Recharts.
- **Audio Architecture**: Native Web Audio API (Procedural synthesis, no external audio files needed).
- **Styling**: Tailwind CSS (Sophisticated OLED dark theme with customizable accent atmospheres).
- **Storage**: Local-First architecture with robust JSON export/backup capabilities.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18+) and npm/bun installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/lifeorbit-os.git
   cd lifeorbit-os
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
